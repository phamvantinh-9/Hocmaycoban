# 📊 Telecom Customer Churn Prediction System

Dự án nghiên cứu và xây dựng hệ thống dự đoán tỷ lệ khách hàng rời bỏ dịch vụ viễn thông (Telco Customer Churn) sử dụng các thuật toán Học máy cơ bản.

## 📌 Thông tin đề tài
- **Môn học:** Học máy cơ bản (Machine Learning)
- **Tập dữ liệu:** Telco Customer Churn (Kaggle Dataset)
- **Bài toán:** Phân loại nhị phân (Binary Classification: Churn Yes/No)
